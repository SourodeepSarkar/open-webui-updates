# Open WebUI for macOS

A native macOS launcher and frontend host for Open WebUI.

This project provides a simple, no-code experience for installing, launching, and accessing Open WebUI on macOS without requiring users to manually work with Python environments, Terminal commands, or local server configuration.

## What This Project Is

This application is a native macOS wrapper around a standard Open WebUI installation.

It helps users:

- Install Open WebUI locally
- Configure the required Python environment
- Launch the Open WebUI server
- Access the web interface through a native macOS application window
- Use Open WebUI without manual setup steps

The application itself does **not** modify Open WebUI, alter its source code, replace any functionality, or introduce changes to the Open WebUI backend.

## How It Works

1. Open WebUI is installed locally on your Mac.
2. A Python virtual environment is created automatically.
3. The Open WebUI server runs locally on your machine.
4. The native macOS application monitors the local server.
5. Once the server is available, the application displays the Open WebUI interface inside a native window.

All AI processing, models, integrations, and Open WebUI functionality continue to be provided by the original Open WebUI software.

## What This Project Does Not Do

This project does not:

- Modify Open WebUI source code
- Rebrand Open WebUI
- Replace Open WebUI functionality
- Provide a custom AI backend
- Add proprietary server components
- Interfere with Open WebUI updates
- Collect Open WebUI data

The application acts solely as a launcher and host for a standard Open WebUI installation.

## Features

- Simplified setup experience

- Lightweight frontend launcher
